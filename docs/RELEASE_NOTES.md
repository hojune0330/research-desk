# Research Desk 0.2.0

Windows x64용 개인 자료 검색 앱의 첫 구현 배포본입니다.

- 파일·폴더·URL·텍스트를 자료함에 추가
- TXT·MD·CSV·HTML·텍스트 PDF·DOCX 추출과 로컬 키워드 검색
- 페이지/추출문 위치와 출처, 중복 기록, 자료 삭제
- OpenAI 키의 Windows 암호화 저장, 자료별 AI 전송 허용
- 허용 발췌문을 사용하는 GPT 대화와 선택적인 웹 검색
- 로컬 대화 보관, 전송 발췌문과 토큰 표시, 결과 내보내기

## 사용할 때 확인할 사항

OpenAI Decisions 평가는 아직 연결하지 않았습니다. 공식 호출 규격과 계정 권한을 확인하기 전이며 현재 검색 결과 순서는 로컬 키워드 순서입니다.

실제 프로젝트 키를 사용한 GPT 생성·웹 검색 호출과 사용자 환경의 기능 동작은 미확인입니다. 코드 문법과 패키징 확인은 기능 시험을 대신하지 않습니다. 앱 설정에서 자신의 키를 직접 입력하며 키 없이 로컬 검색부터 사용할 수 있습니다.

이 배포본은 서명되지 않았습니다. 설치형은 setup, 무설치형은 portable 파일을 받습니다. 파일 해시는 SHA256SUMS.txt에 있습니다. 자세한 지원 범위와 자료 처리 안내는 README·PRIVACY·SECURITY를 확인하세요.
