# Research Desk 0.2.0 구현과 확인 범위

기준일: 2026년 9월 30일.

## 구현

파일·폴더·URL·텍스트의 자료함, TXT/MD/CSV/HTML/PDF/DOCX 추출, SQLite 검색 색인, 키워드와 부분 일치 검색, 원문/발췌문 위치, 중복 기록, 자료 삭제, 자료별 외부 전송 설정, OpenAI 키 암호화 저장, Responses GPT 대화, 선택적인 웹 검색, 인용 ID 검사, 사용 발췌문/토큰 표시, 로컬 대화 저장·삭제, 결과 내보내기를 구현했다.

## 아직 완료되지 않은 연결

OpenAI Decisions의 공식 호출 규격과 계정 이용 권한을 확인하지 못했다. Decisions API는 호출하지 않으며 현재 검색 순서는 로컬 키워드 순서다. GPT의 생성 답변을 Decisions 평가라고 표시하지 않는다.

실제 OpenAI 프로젝트 키는 개발 도구에 입력받지 않았다. 계정의 GPT 생성·웹 검색·실제 과금 동작은 미확인이다. 키는 완성 앱 설정에서 직접 입력하도록 제공한다. 모델 정보 확인은 생성 기능과 Decisions 권한 확인을 대신하지 않는다.

## 확인 작업

코드 문법 확인과 패키징을 수행한다. 별도 기능 시험, 브라우저 자동 시험, 실제 API 호출은 이번 요청에서 실행하지 않는다. 완료한 빌드와 해시, 공개/초안 상태는 해당 릴리스에 기록한다. 패키징 성공은 실제 사용자 환경에서 모든 기능을 확인했다는 의미가 아니다.

## 후속 범위

Decisions 연결, 실제 키를 사용한 기능 확인, 코드 서명, OCR·로컬 의미 검색·자동 폴더 감시·자동 업데이트는 별도 상태로 관리한다. 소스는 사용자가 선택한 MIT 라이선스로 공개한다.
