# Research Desk

많은 자료를 넣고 한 문장으로 찾는 Windows 개인 자료 검색 앱입니다. 로컬 검색은 키 없이 사용하며, OpenAI API를 연결하면 허용한 발췌문을 근거로 GPT와 대화할 수 있습니다.

## 현재 버전

0.2.0은 자료함·로컬 키워드 검색·GPT 대화의 첫 구현입니다. **OpenAI Decisions 평가 연결은 아직 제공하지 않습니다.** 공식 호출 규격과 계정 이용 권한을 확인하지 못해 앱에 연결 준비 상태로 표시합니다. 현재 검색 결과 순서는 로컬 키워드 순서입니다. GPT 답변을 Decisions 평가라고 표시하지 않습니다.

이 저장소의 구현 상태와 확인 범위는 [릴리스 상태](docs/RELEASE_STATUS.md)에 기록합니다.

## 사용 방법

1. 자료 추가를 누르거나 파일·폴더를 앱에 놓습니다. TXT, MD, CSV, HTML, 텍스트 PDF, DOCX를 지원합니다. URL과 텍스트를 붙여넣어도 됩니다.
2. 검색창에 찾는 내용과 필요한 조건을 적고 Enter를 누릅니다. Shift+Enter는 줄바꿈입니다.
3. 검색 근거의 발췌문과 페이지/추출문 행 위치를 확인하고 원문을 엽니다.
4. GPT를 사용하려면 설정에서 OpenAI 키를 저장하고 외부 전송 안내를 확인한 뒤 AI를 켭니다. 자료함에서 해당 자료를 AI 전송 허용으로 변경합니다.
5. 후속 질문은 같은 검색창에 적습니다. 필요할 때만 웹 포함을 켭니다.

자료와 대화는 재시작해도 남습니다. 자료 삭제는 앱의 사본과 색인을 제거하며 가져오기 전 원본은 삭제하지 않습니다. 결과 저장은 사용자가 정한 파일로 내보냅니다. 앱 사용에 GitHub 계정은 필요하지 않습니다.

## API와 자료 보호

- 기본은 AI 끄기, 웹 검색 끄기, 새 자료 로컬 전용입니다.
- API 키는 이 PC의 Windows 사용자 계정으로 암호화합니다. 저장한 키를 화면에 돌려주지 않습니다.
- 자료 추가와 로컬 검색에는 외부 API 호출이 없습니다. URL 추가는 지정한 공개 사이트에서 내용을 가져옵니다.
- AI는 질문과 전송을 허용한 자료의 선택 발췌문, 사용할 수 있는 최근 대화를 OpenAI로 보냅니다. 웹 포함은 입력 검색어를 OpenAI 웹 검색에 보냅니다.
- GPT 호출은 Responses API와 Structured Outputs를 사용합니다. 기본 모델은 GPT-6 Luna이며 모델 접근 권한이 필요합니다. 설정의 모델 이름을 바꿀 수 있습니다.
- API 비용은 사용자의 OpenAI 프로젝트에서 발생합니다. 앱은 반환된 토큰 사용량을 표시하며 확인하지 못한 청구액을 추정 확정액처럼 표시하지 않습니다.
- 원본 사본·색인·대화 전체는 암호화하지 않습니다. [개인정보 안내](PRIVACY.md)와 [보안 범위](SECURITY.md)를 확인하세요.

OpenAI API 안내: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [웹 검색](https://developers.openai.com/api/docs/guides/tools-web-search), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Decisions 발표](https://openai.com/index/devday-2026-recap/).

## 지원 범위

- 파일당 최대 25MB, 한 번에 총 500MB·최대 1,000개. 폴더는 12단계 깊이까지 한 번 가져옵니다.
- 자료당 추출 텍스트 200만 자, PDF 1,500쪽까지. 일부 실패해도 다른 자료는 추가됩니다.
- 스캔 PDF의 OCR, 암호 걸린 문서, HWP/HWPX, 자동 폴더 감시, 의미 검색용 임베딩은 지원하지 않습니다.
- 같은 파일 내용은 중복 추가하지 않고 다른 출처 이름을 기록합니다. 중복으로 추가해도 기존 자료의 전송 허용 상태는 바꾸지 않습니다.
- 한·일·영 키워드와 부분 일치로 검색합니다. 자연어 의미 검색과는 다릅니다. 원문에 없는 정보를 확정하지 마세요.
- 웹 검색 요약은 모델이 생성한 요약이며 수집한 원문 발췌문과 구분합니다. 별도로 URL 추가를 하면 공개 원문을 자료함에 넣을 수 있습니다.

## 개발과 패키징

Node.js 24.11 이상과 Windows x64가 필요합니다. Windows 자료함은 기존 시제품과 같은 사용자 데이터 경로를 사용합니다. 이전 Jev/Exa 키 파일은 읽거나 변경하지 않으며 OpenAI 키는 별도 파일에 저장합니다.

```powershell
npm ci
npm start
npm run package:windows
```

설치 파일과 무설치 실행 파일은 portable-build에 생성됩니다. 설치는 사용자 계정 단위이며 제거해도 자료함을 자동 삭제하지 않습니다. 0.2.0 배포 파일은 서명되지 않았으므로 Windows가 경고할 수 있습니다. 파일 해시는 릴리스의 SHA256SUMS.txt에서 확인하세요.

공개본에는 개인 키·자료·색인·대화가 포함되지 않습니다. 타사 라이선스는 [고지](THIRD_PARTY_NOTICES.md)와 THIRD_PARTY_LICENSES.txt를 따릅니다. 프로젝트 자체의 권리는 LICENSE에 명시합니다.
